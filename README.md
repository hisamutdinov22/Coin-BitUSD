# Coin-BitUSD v2

Новая версия Telegram Mini App:
- бренд Coin-BitUSD и новый логотип;
- тап и прокачка силы;
- 7-дневная серия входов с растущими бонусами;
- задания с наградами;
- недельный турнир и лидерборд;
- отдельная вкладка рефералов;
- реферальные бонусы;
- Telegram WebApp + бот.

## Render
Root Directory: пусто
Build Command: `npm install`
Start Command: `node server.js`
Environment:
- `BOT_TOKEN` — токен бота
- `WEBAPP_URL` — `https://coin-bitusd.onrender.com`
